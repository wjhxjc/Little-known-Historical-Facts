缘起

历史冷知识是一辑以"打破常识"为旨归的小站。我们相信，许多被反复传诵的"历史真相"，其实只是小说演义、戏剧脸谱或教科书为了简化而留下的误差。本站从中挑选了二十桩被广泛误读的中国往事——从蔡伦改良造纸术，到诸葛亮空城计的虚构，再到包拯肤色不黑、雍正朱批段子手——逐一加以考辨，并标明史料出处，供读者趣读、复核。

史料说明

每条冷知识正文末尾都附有"参考 · 史料出处"一栏，标明该条所依据的史籍、笔记或现代学术文献。常用来源包括二十四史各篇、《东京梦华录》《梦粱录》《容斋随笔》《癸辛杂识》等宋元笔记，以及齐藤谦《拙堂文话》、俞茂鲲《痘科金镜赋集解》等专门著述。

本站为科普趣读性质，史料引用力求准确，但难免挂一漏万。如需用于学术研究、论文写作或正式出版，请务必查阅原典与最新学术成果，不要以本站内容为唯一依据。若发现错漏，欢迎通过下方方式反馈。

技术说明

本站是一个零构建的静态网站：没有前端框架、没有打包工具、没有后端服务。所有数据存在 js/facts.js 一个文件里，四个 HTML 页面（首页 / 详情 / 时间线 / 关于）分别用对应的 JS 脚本读取并渲染。代码全部开源，可自由 fork 修改。

  • 字体：Noto Serif SC（思源宋体），系统宋体兜底
  • 色板：墨棕底色 + 羊皮纸米黄正文 + 朱砂印章红强调
  • 响应式：移动端优先，断点 375 / 768 / 1024 / 1440
  • 部署：GitHub Pages 静态托管
